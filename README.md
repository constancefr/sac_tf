## SAC Implementation in PyTorch

Implementation of the Soft Actor-Critic RL algorithm following this [tutorial](https://www.youtube.com/watch?v=ioidsRlf79o).

The agent code is implemented in `sac_pytorch.py`. Run `main_pytorch.py` to train the agent and generate a performance plot + videos.
Alternatively, all code is duplicated inside the demo file `sac_demo.ipynb`, which contains further theoretical explanations and equations from the original paper.
